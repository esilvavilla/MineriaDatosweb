Clase 1: Introducción a la Minería de Datos en Astronomía#

  1. Entender qué es la minería de datos en el contexto astronómico.

  2. Familiarizarse con el entorno de control de versiones, usos de Google Colab y herramientas de machine learning.

  3. Conocer y manejar algunas bases de datos de Astronomía

1. El entorno Colab#

Google Colab es un entorno de Jupyter Notebook que se ejecuta en la nube. Nos permite escribir código y texto en el mismo documento.

print('Hola, Universo!')

Hola, Universo!

Podemos ejecutar comandos de sistema usando el signo de exclamación !.

!python --version

Python 3.9.12

2. Verificando Librerías#

Para este curso necesitaremos varias librerías. Verifiquemos si están instaladas.

import numpy
import pandas
import matplotlib
import astropy

print(f"Numpy version: {numpy.__version__}")
print(f"Astropy version: {astropy.__version__}")
try:
    import astroquery
    print(f"Astroquery version: {astroquery.__version__}")
except:
    print("Astroquery no está instalado por defecto.")
